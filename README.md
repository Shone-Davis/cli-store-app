# CLI Store App

A simple command-line based store management system built in Python.

## Purpose

This project was created as a foundational exercise to understand:
- Python fundamentals
- Control flow and loops
- Functions and basic program structure
- Handling user input in a CLI environment

## Features

- Add and manage products via terminal commands
- Basic inventory-style operations
- Menu-driven CLI interaction

## How to run

```bash
python main.py
```

## Note

This is a learning project and not intended for production use.
